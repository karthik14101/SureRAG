# VERSIONING POLICY
#   Direct dependencies use compatible ranges (>=known-good, <next-major) rather
#   than exact pins. Exact-pinning every package in an app with this many
#   interlocking ML libraries makes pip's resolver fail on the first transitive
#   disagreement, which is exactly what happened with Pillow vs fastembed.
#
#   Transitive dependencies (transformers, huggingface-hub, numpy, tokenizers,
#   onnxruntime, starlette, anyio) are deliberately NOT listed: they are owned by
#   sentence-transformers, fastembed and fastapi, and letting those packages pick
#   their own compatible versions is what keeps the resolve solvable.
#
# NOTE ON TORCH: on Windows, `torch` from PyPI is already the CPU-only build
# (~250 MB). On Linux the default wheel bundles CUDA (~2.5 GB); if you are on
# Linux and want the small CPU build, install torch first with:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
# then run this file.
#
# Requires Python 3.11 or 3.12.
# =============================================================================
